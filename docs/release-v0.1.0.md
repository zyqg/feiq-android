# 飞秋安卓版 v0.1.0

首个公开开发版，适配 Windows 飞秋 / IPMsg 局域网通信。

## 包含功能

- 局域网自动发现与网络重连
- 私聊、历史记录、全局搜索
- 飞秋内置表情与动画表情
- 图片、文件、多文件和文件夹传输
- 文件管理与系统打开
- 联系人分组、手动添加 IP、可配置端口
- 中文化聊天界面和底部导航

## 安装说明

这是未配置正式签名的开发版 APK。下载后直接安装；如果系统拦截，请允许当前来源安装应用。
