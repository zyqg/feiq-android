## 2026-06-08 更新：首张内联图片 15 秒延迟已修复并真机验证

- 修复点：`FeiqEngine` 图片分块 ACK 改为先 ACK 后重组；首 160 块和每 32 块补发 ACK；`UdpChannel` 缓存 `InetAddress`。
- 关键原因：旧源码中第一遍 ACK 发送语句被损坏注释吞掉，实际只发了一遍 ACK，Windows 飞秋首窗口更容易等待 15 秒超时。
- 验证结果：小米手机安装新 debug APK 后，Windows 飞秋发第一张 96456 字节/189 块内联图片，ADB 日志显示 `elapsed=53ms packets=189 dup=0 maxGap=1ms`。
- 新 APK：`G:\opencode\feiq\android\app\build\outputs\apk\debug\app-debug.apk`，已通过 `adb install -r` 安装。
