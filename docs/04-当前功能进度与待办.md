# 当前功能进度与待办

## 2026-06-08 本轮复盘

- 已修复全局搜索跳转：点击结果后可进入对应聊天，并尽量把目标消息定位到列表中部；靠近首尾时会自然贴边显示。
- 已修复文件管理打开问题：文件行正文可直接打开，复选框只负责批量选择。
- 已压缩首页顶部大图区域：首屏留白更少，主列表更紧凑。
- 已移除重复的“本机头像”入口：头像修改只保留在“我的”顶部个人信息卡。
- 已清理本轮扫到的主要用户可见乱码，并补写本地进度记录。
- 已完成构建和真机安装验证。

## 2026-06-08 UI 重构与交互修正

- 聊天页改成更接近微信的输入体验：表情按钮、加号按钮、发送按钮状态切换正常。
- 表情面板支持 96 个飞秋内置表情，并增加右下角 Backspace 删除键。
- 长按气泡改成浮层菜单，空白处不再弹出操作。
- 设置页入口统一收拢到“我的”页面顶部个人信息卡。
- 文件管理页、全局搜索页、主列表和设置页都做了中文化和视觉统一。

## 2026-06-08 协议与兼容修正

- 已修正电脑端昵称后括号设备名的问题，改为使用更合理的身份展示字段。
- 已修正富文本、表情、内联图片、文件传输等核心解析逻辑中的若干兼容问题。
- 已补充局域网发现、文件、图片、搜索、会话管理等能力的本地说明。

## 仍需继续完成

- 真正的群聊和群组协议，还没有完整逆向并实现。
- 头像网络同步协议，还没有完全确认并接入。
- 更完整的历史数据库、导出备份、拉黑、免打扰等功能仍可继续补强。
- 复杂文件预览、全文搜索性能优化和更细的安全策略仍待继续打磨。
