# 飞秋安卓版 —— 安卓工程说明

## 现状（M1+M2 完成）
- 工程位置：`android/`，包名 `com.feiq.droid`，Kotlin。
- 已实现：局域网发现（BR_ENTRY/ANSENTRY）、文字收发（SENDMSG + RECVMSG 回执）、前台服务保持在线、组播锁。
- 协议层 `net/Protocol.kt` `net/PacketCodec.kt` 与 `tools/ipmsg_tool.py`（已实测和飞秋互通）一致，版本段仿飞秋 `1_lbt6_0#...#<MAC>#0#0#0#4001#9`。
- **已成功构建出 APK**：`android/app/build/outputs/apk/debug/app-debug.apk`（约 3.2MB）。

## 构建环境（本机已具备）
- Android SDK: `C:\Users\13652\AppData\Local\Android\Sdk`
- Gradle 9.1.0（缓存里有）、AGP 8.13.1、Kotlin 2.2.20、build-tools 36.0.0、platform android-34/35/36
- JDK：Android Studio 自带 JBR

## 命令行构建
```bash
cd android
./gradlew.bat assembleDebug      # 产出 debug APK
```
> 注意：gradle-wrapper.properties 指向 `gradle-9.1.0-all.zip`（对齐本机缓存，避免重新下载）。
> 首次构建需联网拉取部分 androidx 依赖；之后可加 `--offline`。

## 装到手机（推荐联调方式）
手机和笔记本连**同一个 WiFi**，然后二选一：

**方式A：Android Studio**
1. Android Studio 打开 `android/` 目录
2. 手机开「开发者选项 → USB 调试」，插上 USB
3. 点运行（▶），自动装并启动

**方式B：命令行 adb**
```bash
SDK=/c/Users/13652/AppData/Local/Android/Sdk
"$SDK/platform-tools/adb.exe" install android/app/build/outputs/apk/debug/app-debug.apk
```
（也可以把 APK 拷到手机直接点击安装，需允许「未知来源」。）

## 测试步骤
1. 笔记本启动 FeiQ.exe（正常用）。
2. 手机装好本 App、打开，授予通知权限。
3. App 主界面应出现笔记本上的飞秋用户；飞秋的用户列表里也应出现手机（名字「安卓-机型」）。
4. 点手机里的飞秋用户 → 发消息 → 飞秋应弹窗收到。
5. 飞秋向手机发消息 → App 聊天界面应显示。

## 文件传输（M3，已实现 — 待真机实测）
- 发文件：聊天界面「文件」按钮 → SAF 选文件 → UDP 发 SENDMSG|FILEATTACHOPT 通告 + 起 TCP 服务器(2425)等对方拉取。
- 收文件：收到通告弹框「接收/拒绝」→ 选保存位置(SAF) → TCP 连对方拉流写入。
- 进度显示在聊天界面顶部状态条。
- 代码：`net/FileListCodec.kt`(清单编解码)、`net/TcpFile.kt`(TcpFileServer/TcpFileClient)、`core/FeiqEngine.sendFile/downloadFile`。
- 注意：手机当发送方时要监听 TCP 2425，手机端口独立不与飞秋冲突，可双向测。

## 已知限制 / 下一步
- 文件夹传输（GETDIRFILES 层级流）已实现兼容版，支持发送/接收目录树。
- 飞秋私有富文本字体标签 `{/font;...;}` 收消息时已剥离；表情/头像未解析。
- 消息无持久化（重启丢失）；无重发定时器（仅单发+回执显示）。
- 子网广播：当前用 255.255.255.255；企业网可能需改子网定向广播（NetworkInfo.subnetBroadcast 已备好）。
- 安卓 6+ 取不到真实 MAC，用 androidId 派生的稳定伪 MAC（仅展示用，不影响互通）。
